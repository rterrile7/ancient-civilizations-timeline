## Planned Future Features

### Phase 1: Filter & Compare
- Checkbox or click-to-select civilizations
- Highlight selected; fade others
- Side-by-side comparison panel for 2-5 selected civilizations
- Filter by region, time period, or connection type

### Phase 2: Geographic Arrangement
- Group timeline rows by geographic region:
  - Mesopotamia, Egypt, Levant, Anatolia, Iran
  - Greece/Rome/Europe, Africa, Central Asia
  - South Asia, East Asia, Americas
- Collapsible region groups
- Color-coded region bands

### Phase 3: Map Integration
- Interactive world map alongside timeline
- Time slider synced to both timeline and map
- Show geographic extent of selected civilization on map
- Animate expansion/contraction of empires over time
- Potentially use D3 geo projection or Leaflet.js for map layer
- Globe view option (3D) for dramatic presentation

### Phase 4: Data Enrichment
- Add more civilizations (target: 100+)
- Add key people (rulers, philosophers, generals)
- Add major battles and events as point markers on timeline
- Add trade route overlays on map

### Notes on Architecture
- Keep data in civilizations.json - easy to extend
- Consider splitting into multiple JSON files by region for large datasets
- Map data could use GeoJSON polygons for each civilization's territory
- Time slider would need d3.brush or a custom range input
